# Validation Evidence

This directory contains committed artifacts that prove the charter acceptance
criteria can be met by running the pipeline.

```
validation/
  reference_data/    input data for validation runs
  reports/           live Blender-generated output reports
  images/            demo plots generated from those reports
```

For background on what each test is checking and why, see the methodology docs
in [`docs/validation/`](../docs/validation/):

- [`methodology.md`](../docs/validation/methodology.md) — statistical tests,
  QA metrics, and evaluation procedures
- [`noise-model-mapping.md`](../docs/validation/noise-model-mapping.md) — how
  charter noise parameters map to code
- [`real-bathymetry.md`](../docs/validation/real-bathymetry.md) — real-data
  validation paths
- [`current-results.md`](../docs/validation/current-results.md) — plain-English
  summary of what is demonstrated

For step-by-step commands to reproduce every result here from scratch, see
[`REPRODUCING.md`](./REPRODUCING.md) in this directory.

## reference_data/

| File | Description |
|---|---|
| `cb_noaa_reference_depths.npy` | 1140 depth values (m) extracted from the NOAA Chesapeake Bay M130 2017 netCDF, cropped to the 300 m scene footprint. Used as the KS-test reference for TO3 / D2. |
